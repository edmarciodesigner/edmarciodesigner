# Edmarcio Oliveira — Landing page

Base responsiva em português, criada com HTML, CSS e JavaScript nativos. Abra `index.html` no navegador; não é necessário instalar dependências ou executar build.

## Personalização

- Cores: variáveis CSS `--bg`, `--ink` e `--accent` no início do arquivo.
- Conteúdo: edite os textos das seções no `index.html`.
- Portfólio: substitua os dois exemplos explicitamente marcados como demonstração por trabalhos reais e suas imagens.
- Contato: o botão aponta atualmente para https://edmarciodesigner.com.br/. Substitua pelo seu WhatsApp quando definir o número, usando `https://wa.me/55DDDNUMERO`.
- SEO: atualize o título e a meta description no `<head>`.

## Estrutura

Apresentação, serviços, espaço para portfólio, processo e contato. Layout adaptado para celular, links de navegação internos, foco visível, atalho para o conteúdo e respeito à preferência de movimento reduzido.

## Publicação

O código está pronto para hospedagem estática. Para GitHub Pages, configure Settings → Pages → Deploy from a branch → main → / (root). A publicação não foi configurada nesta entrega.

Sem formulário, coleta de dados, dependências externas ou backend. Nenhum depoimento, resultado ou cliente foi inventado; os exemplos de portfólio são ilustrativos.
